# Backend Project

This is a basic Python backend project managed by `uv`.

## Setup

1.  Navigate into the project directory:
    ```bash
    cd backend-project
    ```
2.  (Optional) Create a virtual environment (already done if you followed the creation steps):
    ```bash
    uv venv
    ```
3.  Activate the virtual environment:
    *   **Windows:**
        ```bash
        .venv\Scripts\activate
        ```
    *   **macOS/Linux:**
        ```bash
        source .venv/bin/activate
        ```
4.  Install dependencies (if any are added to `requirements.txt`):
    ```bash
    uv pip install -r requirements.txt
    ```

## Running the Application

After activating the virtual environment, you can run the main application:

```bash
python main.py
```

## Deactivating the Virtual Environment

To deactivate the virtual environment, simply run:

```bash
deactivate
```
